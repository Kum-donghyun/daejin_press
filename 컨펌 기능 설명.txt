이제 컨펌 기능을 완성합시다. 편집장은 먼저 하단의 '바로 승인하기' 버튼을 이용해 컨펌 없이 바로 승인이 가능합니다.
만약 1차 컨펌(삭선과 추가 사항 표시 등)을 시작하면 그 즉시 '바로 승인하기' 버튼은 비활성화되고 1차 컨펌 완료 시
'바로 승인하기' 버튼 좌측에 '컨펌하기' 버튼을 클릭하여 담당 기자가 인지할 수 있도록 하면 좋겠네요.

컨펌하기가 완료되면 해당 기사의 담당 기자 계정으로 알림이 뜨고 편집장 패널에 컨펌 알림은 사라집니다.(바로 승인 시에도 마찬가지)
기자는 컨펌된 기사에서 삭선과 추가할 내용을 확인한 뒤 수정이 가능하게끔 해줘요. 가능하다면 삭선(빨간 텍스트)이 표시된 텍스트에 마우스 홀드 시 지우기 버튼이 표시되고 클릭 시 해당 구문 삭제, 파란색 텍스트에 마우스 홀드 시 추가하기 버튼이 표시되고 클릭 시 파란색 텍스트가 검은색 텍스트로 변환되게 해줘요.
여기에 더해 컨펌 후 기사 수정 과정에서의 기본 기능으로 검은색 텍스트로 자유롭게 편집할 수 있도록 해줘요.
기자의 기사 수정 화면 속 하단에는 '편집장 컨펌 요청' 버튼이 있어야 하고 기자는 수정 완료 시 이 버튼을 통해 컨펌 재요청을 하고 편집장은 다시 컨펌 또는 바로 승인하는 로직이 반복됩니다.

이제 편집장이 '바로 승인하기' 버튼을 눌렀을 때 승인된 기사가 메인 페이지에 어떻게 표출되는지 설명하겠습니다.
먼저 승인된 모든 기사들은 '섹션 2: 큐레이션 탭'에서 볼 수 있습니다.
 tabs라는 이름으로 정의된 리스트를 ['전체뉴스보기', '(1면 탑 기사 제목)', '(2면 탑 기사 제목)', '(3면 문화면 1 기사 제목)', '(4면 칼럼 제목)', '(5면 기획 탑 기사 제목)', '(6면 기획 1 기사 제목)']으로 정의될 수 있도록 해주고 만약 해당 기사가 입력되지 않았다면 아무 탭도 표시되지 않습니다.
 전체뉴스보기에는 1면 탑부터 부탑, 2면의 기사들, 3면의 기사들 순서대로 모든 승인된 기사만이 표출됩니다.
 1면 탑 기사 제목 탭으로 이동하면 1면의 기사들만, 2면 탑 기사 제목 탭으로 이동하면 2면의 기사들만 표출되는 방식입니다.
 이 '섹션 2: 큐레이션 탭'의 기사들은 가장 최신 호의 승인된 기사들이며 기존 호수의 기사가 배치된 상태에서 다음 호수의 각 지면 기사가 새로 승인되면 이 큐레이션 탭에서는 기존 기사가 표출되지 않습니다.

각 큐레이션 탭 내 카드에는 기사 제목과 보도 이미지, 기자명이 적절하게 들어갈 수 있도록 해주시고 이미지가 없는 기사도 카드 내 이미지 표출 부분이 없되 기본 카드 크기에 맞춰 제목과 부제, 본문이 적절하게 표출될 수 있도록 해줘요.
보도 이미지만 있는 한컷대진은 이 큐레이션 탭에 표출되지 않아도 됩니다.
학생자치, 학술, 오피니언과 같이 기사의 카테고리를 보여주는 태그는 '문화면' 기사의 경우 '문화'로, '칼럼' 기사의 경우 '교수칼럼'으로, '기자한마디' 기사의 경우 '기자한마디'로, '조명탑' 기사의 경우 '오피니언'으로, '기획' 기사의 경우 '기획'으로, '지역사회' 기사의 경우 '지역사회'로 카테고리를 지정해줘요.
현재 큐레이션 탭에 존재하는 제보하기 카드는 그대로 남겨주시고 각 탭의 기사 카드 개수가 4개 이상이어도 좌우 스크롤을 통해 옆으로 넘길 수 있게 해줘요.
