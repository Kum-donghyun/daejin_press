먼저 일반 독자의 권한을 3가지로 나누겠습니다.
비로그인 사용자 / 로그인한 일반 독자 / 실명 독자(댓글 권한 승인)

그리고 현재 기사 조회수 카운트 기능이 제대로 작동하는지 살펴봐줘요. 이때 조회수는 
비로그인 사용자 / 일반 독자 / 실명 독자까지 기자와 편집장을 제외한 독자가 기사 상세 
페이지에 진입할 때만 적용되고 이 조회수 정보는 해당 뉴스 기사를 표출하는 모든 카드 내에 
표시되어야 합니다. 또한 독자들이 해당 기사 페이지에 평균적으로 머문 시간도 측정해줘요. 
조회수와 페이지 렌딩 시간(실질 조회수)은 관리자 패널과 기사 작성 화면에서 각 기사별로 
수치가 표시될 수 있도록 해줘요. 수치 데이터는 DB를 활용해 저장하고 프론트에서 시각화해도
됩니다.

또한 앞으로 메인 페이지의 '전체 뉴스 보기' 섹션은 '대진대 핫이슈'로 변경되며 이곳에는 
신문 호수, 온라인 뉴스 여부와 상관 없이 최근 일주일 간 제일 조회수가 많이 올라가고 
페이지 랜딩 시간이 길며 댓글이 많은 기사들을 각 요소 변수 영향 3:2:1 비율로 계산해
차례대로 표출되도록 합니다.

한편 일반 독자까지의 회원가입 방식은 현재와 똑같지만, 실명 독자가 되기 위해서는 학생(졸업생 포함)의 
경우 학과, 학번, 이름 입력 및 개인정보 제공 약관 동의가 필요하고 교수, 교직원의 경우 
학과(부서), 교번, 이름 입력 및 개인정보 제공 약관 동의가 필요하며 실명 사용자 중복 발생 
또는 댓글로 인한 문제 발생 시 인증 절차가 진행될 수 있다는 점을 고지해야 합니다.
이후 학생의 경우 8자리 학번(앞 네 자리는 입학 년도; 19OO-20OO년이어야 함)에 학과와 이름
필수 입력 조건으로 실명 가입을 자동 승인해주고 교수와 교직원은 편집장의 
알림을 통해 직접 승인할 수 있도록 해줘요. 학생 실명 가입 자동 승인 시 편집장에게 
알림으로 정보가 제공되어 이상치가 발견될 수 있도록 해줘요.

실명 독자는 이제 각 기사에 댓글을 작성할 수 있습니다. 모든 사용자는 실명 독자가 작성한 
각 기사 상세 페이지 내 댓글들과 댓글 작성란을 볼 수 있지만, 실명 독자에게만 작성란에 
작성이 가능하다는 점을 고지해줘요. 댓글 작성자는 수정 및 삭제가 가능하고,
댓글에는 실명 독자와 기자, 편집장에 한해 답글이 가능하며 
편집장의 권한으로 댓글과 답글 블러 처리(클릭 시 블러 해제), 삭제 처리가 가능합니다.
